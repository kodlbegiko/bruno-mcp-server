# 《深刻認識一個人》 (Deeply Know Someone) · v1.0.0

> 「有些人認識很久，卻從來沒有真正認識過彼此。」  
> 一副存在手機裡的實體感對話卡牌。

《深刻認識一個人》是一款面對面進行的關係對話卡牌遊戲。核心不是競爭、勝負、分數或排行榜，而是**讓兩個或多個人，透過逐步加深的問題，更真實地認識彼此**。

---

### 🎯 最高優先原則

1. **題目內容嚴謹審查**：
   - **經典版 (70 題)**：嚴格對照官方實體卡牌原稿素材（10 暖身 + 20 一星 + 20 二星 + 20 三星，0 張私自加減、0 改寫）。
   - **深度擴充版 Expansion V1 (60 題)**：15 暖身 + 15 一星 + 15 二星 + 15 三星，全數通過 Content Review Workflow（`reviewStatus: 'approved'`），並附帶專屬「深入追問」（Follow-Up）引導。
   - **完整題庫 (130 題)**：無縫融合經典與擴充，支援自訂模式任意選擇題庫。
2. **面對面互動不被手機打斷**：手機是「牌盒＋主持人」，翻牌後注意力回到彼此對視與聆聽，絕不要求「每人回答後按完成」。
3. **心理安全感與對話節奏引導 (Adaptive Conversation Engine)**：
   - 任何人隨時可以「**換一題**」或向左滑動換題，不需理由、零懲罰，引擎自動根據跳過訊號避開同主題或敏感度。
   - 智慧對話弧線演算法（Topic anti-clumping, emotional breathing space, sensitivity spacing）引導對話漸進加深。
   - 進入三星前設有嚴謹的多人全體同意／單機守護同意機制。
4. **可靠的狀態保存**：遊戲進度即時自動保存至本機 `localStorage`，重新整理或誤觸關閉可一鍵「繼續上次遊戲」。
5. **精確的隱私保護模型**：
   - **單機／共用模式**：100% 本機運行且離線可用，完全不發送遊戲內容。
   - **多人模式**：基於 WebRTC P2P 點對點連線同步卡片狀態，無集中伺服器存取對話內容。
   - 絕不錄音、絕不記錄玩家對話語音或文字內容、無須註冊登入。

## 🌟 核心特色與體驗優化

- 🧠 **Adaptive Conversation Engine (智慧對話引導系統)**：
  - **開場契合度**：自訂遊戲可選擇對象關係情境（初識／朋友／多人／約會／伴侶／家人），開場第 1 張牌即精準對齊氛圍。
  - **節奏舒緩與呼吸空間**：重度情緒題後自動插入沉澱或溫暖分享題，避免連環情緒轟炸。
  - **話題防群聚 (Anti-Clumping)**：自動分散家庭、童年、工作、價值觀等不同維度。
  - **💬 深入追問 (Follow-Up Prompts)**：精選深度題附有延伸追問引導，提供延伸對話的梯子。
- 🌐 **WebRTC P2P 多人同步連線 (權威房主模型)**：
  - 遊戲狀態透過 WebRTC P2P 點對點連線同步卡片狀態，不由中央伺服器儲存對話內容，房主一鍵開房，房客各自手機即時同步翻牌與主持棒輪替。
  - 房主權威狀態機（Host-Authoritative State Machine），防止房客跨權限重置或篡改牌局。
  - 內建 7 組全球公用高可用性 STUN 節點，搭配 3.5s 心跳包 (Ping/Pong) 監控看門狗，異常中斷 9s 內自動觸發重連。
- 📸 **QR Code 相機掃描加入**：
  - 支援動態 QR Code 生成與本機相機掃描儀 (`html5-qrcode`)，免輸入 6 碼代碼，一掃即入房。
- 👆 **Tinder 式物理滑動手勢**：
  - 卡牌翻開後支援自然的手勢拖曳：**向右滑動（下一張）**、**向左滑動（換一題）**，附帶觸覺震動回饋與動態指示標籤。
- 🌙 **質感深色模式 (Night Mode)**：
  - 支援系統跟隨與手動切換（淺色 / 深色 / 系統），暖調炭黑紙質配色，深夜微醺長談柔和不刺眼。
  - 自動更新手機狀態列 `<meta name="theme-color">`。
- 🚀 **原生社群分享 (Web Share API)**：
  - 結算頁面支援原生分享面版（一鍵分享至 IG 限動、LINE、Threads），若無支援則自動降級至剪貼簿複製。
- ⚡️ **零延遲預載 (Zero-Latency Prefetching)**：
  - 背景預熱卡背貼圖與下一張題目數據，翻牌換題徹底零延遲。
- 📶 **PWA 漸進式網頁應用與離線支援**：
  - 遵循 Workbox 快取架構（圖片靜態 30 天 CacheFirst、HTML NetworkFirst）。
  - 斷線時優雅浮現離線狀態提醒，單機卡牌離線亦可暢玩。
- 👁 **螢幕防休眠 (Screen Wake Lock)**：
  - 對話進行中自動鎖定螢幕常亮，避免深談時手機黑屏中斷氛圍。
- 🌐 **雙語與國際化 (i18n)**：
  - 支援繁體中文與英文介面切換，支援卡牌底部英文副標題對照。
- ♿️ **無障礙體驗 (a11y)**：
  - 完整考量鍵盤操作、螢幕閱讀器與對話框焦點管理，內建 `LiveAnnouncer` 動態語音播報主持進度。

## 🛠 技術堆疊

- **前端框架**：React 19 + TypeScript 5
- **構建工具**：Vite 6.0 (動態代碼分塊 + PWA Service Worker 生成)
- **樣式與動效**：Tailwind CSS + Framer Motion
- **狀態管理**：Zustand 5 (模組化切片架構)
- **音效合成**：Web Audio API 原生物理音效合成（免載入任何 mp3）
- **觸覺回饋**：Navigator Vibration API
- **測試體系**：
  - **Vitest**：111+ 項單元與整合測試（題庫完整性、Review Workflow 門禁、智慧節奏演算法、洗牌隨機度、角色指派、Zustand 切片、WebRTC 心跳、深色模式、手勢等）
  - **Playwright**：16 項端到端跨裝置自動化測試（涵蓋 Mobile iPhone 14 與 Desktop Chrome 全流程）
