# 《深刻認識一個人》遊戲規則手冊

> 「有些人認識很久，卻從來沒有真正認識過彼此。」

《深刻認識一個人》是一款為面對面對話設計的數位實體感卡牌遊戲。核心不是競爭、勝負、分數或排行榜，而是透過逐步加深的問題，讓大家更真實、放鬆且深刻地認識彼此。

---

## 核心規則（一分鐘看懂）

1. **輪流抽牌**
   每抽一張新卡，由下一位玩家負責抽牌（Drawer）。手機放在大家中間，就像桌上的實體卡牌盒。

2. **照著卡片回答或互動**
   - 題目顯示後，手機只負責提問。大家把視線移回彼此眼前，自然聊天。
   - 大多數題目由抽卡者分享；部分特殊卡片會由「全體回答」、「其他人對抽卡者回答」或「指定一位玩家互動」。

3. **換一題不需要任何理由**
   任何時刻、任何階段，若不想回答目前的題目，按「換一題」即可跳過，同局不會再次出現。沒有懲罰、不扣分、不記錄次數。

4. **由淺入深的四個階段**
   - **暖身破冰 (Break The Ice)**：10 張趣味、生活、拍照與輕鬆分享。
   - **★ 一星連結 (One-Star Connection)**：20 張關於興趣、習慣、童年與社交特質。
   - **★★ 二星連結 (Two-Star Connection)**：20 張關於情緒、人際、脆弱與自我價值。
   - **★★★ 三星連結 (Three-Star Connection)**：20 張關於人生重大經驗、家庭、挑戰與深層記憶。（進入前提供溫和自主同意確認）

5. **沒有勝負，只有更靠近**
   任何時候都可以結束遊戲，系統只會溫柔回顧今晚聊過的張數與時間，留下一段美好的相處時光。

---

## 互動類型說明

| 類型代碼 | 說明 | 角色示範 |
|---|---|---|
| `single` | 抽卡者單人回答 | 抽牌者一人分享自身經歷 |
| `all` | 所有玩家依序分享 | 順時針每位玩家都回答一輪 |
| `othersToDrawer` | 其他人針對抽卡者回答 | Drawer 為主角，其餘玩家分享對 Drawer 的第一印象或祝福 |
| `chooseOne` | 抽卡者挑選一人互動 | Drawer 點選一位玩家表達感謝或互動任務 |
| `action` | 執行任務卡 | 例如大家合影打卡、做鬼臉合照等互動行動 |
