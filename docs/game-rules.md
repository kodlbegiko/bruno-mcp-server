# 《深刻認識一個人》遊戲規則手冊

> 「有些人認識很久，卻從來沒有真正認識過彼此。」

《深刻認識一個人》是一款為面對面對話設計的數位實體感卡牌遊戲。核心不是競爭、勝負、分數或排行榜，而是透過逐步加深的問題，讓大家更真實、放鬆且深刻地認識彼此。

---

## 核心規則（一分鐘看懂）

1. **輪流抽牌**  
   每抽一張新卡，由下一位玩家負責抽牌（Drawer）。手機放在大家中間，就像桌上的實體卡牌盒。

2. **照著卡片回答或互動**  
   - 題目顯示後，手機只負責提問。大家把視線移回彼此眼前，自然聊天。
   - 大多數題目由抽卡者分享；亦有全體輪流、雙人對話、眾人對抽牌者、或自由討論等多元互動。

3. **換一題不需要任何理由**  
   任何時刻、任何階段，若不想回答目前的題目，按「換一題」或向左滑動即可跳過，同局不會再次出現。沒有懲罰、不扣分、不記錄次數，對話引擎會自動感應並調整後續題目的主題或敏感度。

4. **由淺入深的四個階段**  
   - **暖身破冰 (Break The Ice)**：趣味、生活觀察與輕鬆分享，打破初期拘謹。
   - **★ 一星連結 (One-Star Connection)**：關於興趣習慣、童年記憶、社交特質與價值觀初探。
   - **★★ 二星連結 (Two-Star Connection)**：關於邊界感、信任、情緒、脆弱與自我價值。
   - **★★★ 三星連結 (Three-Star Connection)**：關於深層生命經驗、修復、遺憾與靈魂共鳴。（進入前提供溫和自主同意確認，需全體同意方可進入）

5. **沒有勝負，只有更靠近**  
   任何時候都可以結束遊戲，系統只會溫柔回顧這場對話聊過的張數與時間，留下一段美好的相處時光。

## 互動類型說明

遊戲內卡牌涵蓋 7 種面對面互動機制，依卡片標籤清晰指引：

| 類型代碼 | 名稱 | 說明與角色指引 |
|---|---|---|
| `single` | 單人分享 | 抽牌者一人分享自身經歷或看法。 |
| `all` | 全體輪流 | 順時針每位玩家依序分享一輪。 |
| `pair` | 雙人對話 | 抽牌者與指定對象面對面交流對話。 |
| `othersToDrawer` | 對抽牌者分享 | 抽牌者為主角，其餘玩家分享對抽牌者的觀察、印象或感謝。 |
| `chooseOne` | 指定一人互動 | 抽牌者從在場玩家中挑選一人回應或互動。 |
| `discussion` | 自由討論 | 全體成員針對主題自由延伸探討，無特定發言先後順序。 |
| `action` | 任務行動 | 共同合影、擊掌、眼神注視等破冰任務。 |

## 深入追問 (Follow-Up Prompts)

部分深度卡片附有 **「再問深一點」** 深入追問功能：
- **可選引導**：當大家意猶未盡、想要更深探討時，抽牌者可點擊展開延伸問題。
- **即時同步**：多人模式下，抽牌者展開追問會即時同步至全體玩家螢幕。
- **節奏適應**：展開追問會向系統提供積極訊號，自然延長同層次的探索深度。

## 關係情境與智慧對話引擎 (Adaptive Conversation Engine)

系統內建 Adaptive Conversation Engine，讓每次抽牌都有如專業對話引導師在旁陪伴：

1. **關係情境對齊 (Relationship Fit)**：
   開局可選擇對話對象情境：
   - **初識 (New Friends)**：優先出現生活化、安全且高共鳴的題目。
   - **好友 (Friends)**：加強回憶與朋友間的默契探索。
   - **約會 (Dating) / 伴侶 (Couples)**：強化價值觀、情感期待與深層親密連結。
   - **家人 (Family)**：適配親情、家庭成長背景與跨世代溝通。
   - **多人聚會 (Group)**：側重全員參與感與群體互動題。
   開場第一張題目即以最高契合度算法精確對齊。

2. **智慧對話弧線 (Conversation Arc)**：
   - **主題防群聚 (Topic Anti-Clumping)**：自動避免相同主題連續出現（例如避免連抽三張童年或衝突題）。
   - **情緒呼吸空間 (Emotional Breathing Space)**：重度情感題後自動插入沉澱或溫暖題，避免高壓疲乏。
   - **敏感標籤間距防護 (Sensitivity Spacing)**：對涉及悲傷、衝突或重度親密關係的題目實施自動間距排程。
   - **動態跳過適應**：若玩家跳過某張牌，引擎自動避開該主題或敏感性，給予舒適的空間。

## 遊戲模式

1. **深度旅程 (Guided Journey)**  
   系統依照破冰 → 一星 → 二星 → 三星的節奏自動推進，在各階段收集到足夠深刻的投入題數後，由大家決定是否晉級下一層次。

2. **自由抽牌 (Free Play)**  
   自由選擇起始星級，隨時可於選單中自由切換牌組，適合熟練玩家或特定深度的交流場合。
